# Kinematics Motion dataset

## Проблема
> Умное устройство собирает данные о физической активности пользователя включая показания акселерометра, гироскопа, временные метки и метку запястья. Необходимо определить тип активности (ходьба / бег). Так как вручную данные обрабатывать неэффективно, требуется построить модель машинного обучения

## Структура
- `src/` - Код проекта
- `train.py` - Обучение и сохранение модели
- `infer.py` - API для обращения к обученной модели
- `notebook/` - Эксперименты (сравнение моделей, оценка значимости признаков и т.д.)
- `data/` - Данные для обучения
- `model/` - Сохраненные модели

## Запуск
- `pip install -r requirements.txt` - Установить зависимости
- `py ./train.py` - Обучить модель
- `uvicorn infer:app` - Запустить API модели
- `config.py` - Изменить параметры, модель и т.д.

## Данные (датасет)
Kinematics Motion Data - https://www.kaggle.com/datasets/yasserh/kinematics-motion-data/
